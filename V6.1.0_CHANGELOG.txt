HOA V6.1.0 — FEATURE-LEVEL JAVASCRIPT SEPARATION

Base: verified working HOA V6.0.9 JavaScript Foundation build.

Purpose
- Begin feature-level JavaScript separation without changing section flow or database workflows.
- Keep execution order identical to V6.0.9 by replacing selected inline script blocks with external <script src> references at their original positions.
- Establish clear directories for future modular refactoring.

Externalized feature modules
- Student: paid registration, login state/guards, content access, free student portal, course/mock portals.
- Admin: management, CRUD, direct CRUD, posters, content management, permissions, free-content workspace, course/video workspaces, batch360, mock-test workspace.
- Core: legacy consolidation layer (kept as a compatibility module for later refactoring).

Still inline by design
- Main legacy application core and smaller runtime/compatibility patches remain inline for this stage.
- This avoids changing dependency order or increasing network request count more than necessary.

Validation
- All external JS files pass Node syntax validation.
- 0 duplicate DOM IDs in parsed HTML.
- All local JS/CSS/logo references return HTTP 200 from a local static HTTP server.
- CSS remains external from V6.0.8.
- V6.0.9 source remains untouched.
